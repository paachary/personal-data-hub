# Statements Help

> 🔐 Not available to the sysadmin

## Overview

Import bank statements for your accounts and review your balances, spending and trends.

## Features

-   **Import** a statement with **📥 Import Statement**
-   **View** imported statements, with their date range, opening and closing balance, total debits and total credits
-   **Browse** every transaction in the statement list, with a filter box
-   **Analyze Trends** over a date range, using **Daily**, **Weekly**, **Monthly** or **Yearly** totals
-   **Clear Data** to delete imported statement data for the selected account, or for all accounts

## Importing a Statement

1. Select the **Bank**. The supported banks are HDFC, ICICI, SBI, Union Bank of India and Standard Chartered.
2. Select the **Account** you are importing into.
3. Select the **Format**: **CSV File** or **Excel File** (`.xlsx` / `.xls`).
4. Select the file and click **Import Statement**.

The app reads the opening and closing balance, totals and every transaction. When the import finishes, it shows an **Import Summary**.

## Supported Formats

-   **Supported**: CSV and Excel statements from HDFC, ICICI, SBI, Union Bank and Standard Chartered.
-   **Other banks**: the generic CSV or Excel reader is used. It works only if the columns match the expected layout.
-   **Not supported**: PDF. Export your statement as CSV or Excel from your bank's portal first.

## Tips

-   Importing the same statement again does not create duplicate transactions.
-   **Clear Data** cannot be undone. Use it only when you need to remove statements, for example before re-importing a corrected file.
-   Trend analysis uses the data already imported. Import the latest statement to see recent spending.
