# All Accounts Help

> 🔐 Sysadmin only

## Overview

View the bank accounts of all users in one table.

## Features

-   **View** every user's bank accounts, with the user, bank, branch, city, account number and account type
-   The table is **read-only**. Users manage their own accounts.

## Tips

-   To change the list of banks users can choose from, use **Bank Master** under **Admin** in the sidebar.
