# Dashboard Help

## Overview

The Dashboard gives you a quick summary of all your personal data.

## What You'll See

| Card          | Description                               |
| ------------- | ----------------------------------------- |
| Passwords     | Total saved vault entries                 |
| Secure Notes  | Total saved notes                         |
| Pending Todos | Number of **pending** todos (not done)    |
| Investments   | Total investment records                  |
| Accounts      | Total bank accounts linked to you         |
| Banks         | Total banks in the Bank Master list       |

## Tips

-   Click any section from the **sidebar** to navigate to it.
-   Counts are loaded each time the dashboard opens.
-   The sysadmin cannot open Passwords, Secure Notes or To-Do pages, so those counts are not available to the sysadmin.
