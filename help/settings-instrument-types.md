# Settings — Instrument Types Help

> 🔐 Sysadmin only

## Overview

Manage the types of financial instruments available when adding investments.

## Default Instrument Types

| Code  | Description                  |
| ----- | ---------------------------- |
| FD    | Fixed Deposit                |
| MF    | Mutual Funds                 |
| LIC   | Life Insurance               |
| NPS   | National Pension Scheme      |
| MI    | Medical Insurance            |
| ELSS  | Equity Linked Savings Scheme |
| PPF   | Public Provident Fund        |
| BONDS | Bonds                        |

## Features

-   **Add** new instrument types
-   **Edit** existing types
-   **Delete** types (you are asked to confirm)

## Tips

-   Deleting a type is not blocked when investments use it. Check existing investments before you delete a type.
-   The types you add here appear in the **Instrument** dropdown on the Investments form and in the Reports filters.
