# All Investments Help

> 🔐 Sysadmin only

## Overview

View the investments of all users in one table.

## Features

-   **View** every user's investments, with the user, name, bank, instrument, type, amount and dates
-   **Filter** by **Bank**, **Instrument** and **Type**
-   Switch between **All**, **Active** and **Closed** investments
-   **Export** the visible investments to Excel (`.xlsx`) with **📥 Export to Excel**

## Tips

-   The table is **read-only**. Users edit their own investments.
-   A closed investment is one whose maturity date has passed.
