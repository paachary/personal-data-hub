# Investment Reports Help

> 🔐 Sysadmin only

## Overview

View a consolidated report of investments and bank debits across all users.

## Reports

-   **All Active Investments**: active investments across all users, grouped by instrument type, with a donut chart. The chart follows the filters.
-   **SIP Only**: active SIP investments across all users.
-   **Monthly Debit Summary by User**: monthly debits per user, grouped by bank. Sections can be collapsed and sorted.
-   **Monthly Debit Summary**: monthly debit totals across users.

## Features

-   Filter the investment tables by **User**, **Bank**, **Instrument** and **Type**. Each filter accepts multiple values.
-   See the **Total Invested** amount for the filtered rows.
-   Export investment data to Excel (`.xlsx`).

## Tips

-   Use the filters to narrow a report to one user, bank or instrument.
-   Only active investments appear in the investment reports. Closed investments (matured) are excluded.
-   Investments are read-only here. Make changes from the user's own **Investments** page, or from Bank Master for bank data.
