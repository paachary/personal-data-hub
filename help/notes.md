# Notes Help

## Overview

Store private notes securely, accessible only to you.

> 🔐 Regular users only. The sysadmin sees a restricted message on this page.

## Features

-   **Add** a new note with **+ Add Note**
-   **Edit** existing notes
-   **Delete** notes (you are asked to confirm)
-   Each note can include:
    -   **Title** (required), **URL**, **Description**, **Content**
    -   **Tags** to help you organise notes
    -   **Custom attributes**: key-value pairs. Use a password-type attribute to mask its value.

## Tips

-   Notes are private. The sysadmin cannot read them.
-   Use notes for sensitive text like PINs, security answers and recovery codes.
-   Use custom attributes for structured details, such as a locker number and its key.
