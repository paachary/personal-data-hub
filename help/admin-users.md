# Admin — User Management Help

> 🔐 Sysadmin only

## Overview

View all registered users and manage their passwords and MFA.

## Features

-   **View** all registered users, with name, username, email, city/state, role and status
-   **Reset Password** for a user
-   **Reset MFA** for a user

## Status Badges

-   **Active**: the user can log in normally.
-   **Reset Pending**: the user's password was reset and must be changed on next login.

## Tips

-   When you reset a password, the user will be forced to change it on next login.
-   When you reset MFA, the user will be asked to set up MFA again on next login.
-   New users register themselves from the **Register** link on the login screen. There is no admin "create user" action.
-   User accounts cannot be deleted from this screen.
