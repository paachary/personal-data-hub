# Settings — Investment Types Help

> 🔐 Sysadmin only

## Overview

Manage the investment modes available when adding investments.

## Default Investment Types

| Code    | Description                |
| ------- | -------------------------- |
| LUMPSUM | Lumpsum / One Time         |
| SIP     | Systematic Investment Plan |
| SWP     | Systematic Withdrawal Plan |
| STP     | Systematic Transfer Plan   |

## Features

-   **Add** new investment types
-   **Edit** existing types
-   **Delete** types (you are asked to confirm)

## Tips

-   Deleting a type is not blocked when investments use it. Check existing investments before you delete a type.
-   The types you add here appear in the **Investment Type** dropdown on the Investments form and in the Reports filters.
